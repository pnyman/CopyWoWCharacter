# Copy WoW Character Settings

Copies settings and macros from one WoW character to another.

Tested to work on Turtle WoW.

## Operation
* Set your WoW-directory in the Settings menu.
* Select characters to copy from and to.
* A zip-file with the old settings will be created as backup
  in the receiving character's directory.

## Compilation
* Download the project from Github.
* Download [Lazarus](https://www.lazarus-ide.org/).
* Open the project in Lazarus and compile it there, or...
* Run `lazbuild CopyWoWChar.lpi` in terminal.
